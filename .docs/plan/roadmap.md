# Unruled roadmap

Where the project is heading, why, and rule exceptions. Build order follows GDD §5 (Sprint 1–5).

## Decisions

- 2026-10-16 — **Simulation is a hand-rolled pure C# ECS in `Unruled.Core`, not Unity DOTS.** Performance with flat struct arrays, while staying deterministic, engine-free (runs on the headless Server 2 and WebGL) and portable to Rust later; DOTS would tie the sim to Unity APIs and non-deterministic Burst floats. DOTS is allowed only in `Unruled.View` for rendering if profiling demands it.
- 2026-10-16 — **Fixed-point instead of the GDD §3 `float` fields** (`BaseEsi`, `PosX/PosY`, `HullIntegrityPct`, …). The GDD class shapes become ECS components with integer/milli-unit values for cross-platform determinism.
- 2026-10-16 — **System generator uses SplitMix64 only (GDD says SplitMix64 + ChaCha8) and integer trig (`FixedMath`).** ChaCha8 adds no gameplay value; integer math keeps layouts bit-identical across platforms and in a Rust port. The RNG draw order is part of the save contract.
- 2026-10-16 — **Universe layout numbers are provisional** (`DefaultGameBalance.CreateUniverseGenBalance`: 8 orbits, r 300 + 180·i ± 25, R_HZ 840, W_HZ 700, ±0.05 atmo noise, ±10° jitter); only the 120 min spacing is from the GDD. Move them into the data sheet when designed.
- 2026-10-16 — **WHO quarantine is a per-site system (`WhoQuarantineSystem`), not a refinery state.** GDD §2.2 A.4 says it locks export launches off the planet, so production keeps running; exports check `SiteQuarantine.IsExportLocked`.
- 2026-10-16 — **Shared components (e.g. `Stockpile`) may be changed by several systems** through their own methods, in the fixed `SimClock` order (rule 4 amended). Refinery upkeep is accrued in `Refinery.AccruedUpkeep` until a credits ledger exists; base upkeep 10/cycle and 1 battery per storm cycle are provisional.
- 2026-10-16 — **Mining numbers are partly provisional** (`DefaultGameBalance.CreateMiningBalance`): depth speeds, fuel/coolant multipliers and ESI drops come from data sheet tab 02; the 10-tick cycle, 10 ore and 1 fuel + 1 coolant per rig per cycle are proposed until the sheet defines them. Depths are mined surface → deep crust → core fracture (only when unlocked), never mixed in one cycle.
- 2026-10-16 — **`PlanetLifecycleSystem` owns site lifecycle and ESI** (moved out of `MiningSystem`, rule 4). A nuclear strike enters through `ApplyNuclearStrike`, called by the Sprint 3 combat engine, not by a player command, so it can't be fired for free. Terraform is a command, paid from the site stockpile; its cost (100 water/N2/biomass + 1 nuclear core) and instant ESI → 0.60 are provisional, and the Tier 5 gate waits for the Research module.
- 2026-10-16 — **`DelayedPlayerCommand` carries `TargetGeneration`** with `TargetEntityId`, so a command aimed at a destroyed entity misses instead of hitting a reused index. Nothing is serialized yet; the MessagePack keys get assigned when networking starts.
- 2026-10-16 — **Starlane topology is provisional** (`StarlaneGenerator`): an STA highway between every pair of neighbouring orbits keeps each system connected; a 50% outer-rim bypass between orbits 2 apart and a 25% storm shortcut between orbits 3 apart. Lanes between systems wait for the multi-system map. Tab 04's "Storm G0/S0 · G1–G2 · G4/S4/R4" is read as the highest storm level the lane is exposed to (0 / 2 / 4).
- 2026-10-16 — **NOAA storm spawning is provisional** (`CreateNoaaBalance`): each system rolls every 600 ticks with a 25% chance of a front (level odds 40/30/17/10/3%, lasting 30 min – 3 h, radius 150–500). The GDD names the R/S/G scales but gives no spawn model. Rolls draw from a fresh `SplitMix64` keyed by (world seed, tick, cluster), so the engine keeps no RNG state and saves don't need one. Weather is recomputed every tick (sites × fronts); make it incremental if profiling asks for it.
- 2026-10-16 — **Signal latency rules as built** (`SignalLatencySolver`, `CommandIssuer`): a hop is relayed (8 instead of 35) when the site it reaches has the player's relay station or EW fleet, or the lane it crosses carries the player's EW fleet. A fleet on a lane counts as one hop past the nearer end. An R3+ radio blackout on the target refuses the order (provisional reading of GDD §1.1); laser comms come with Tier 4 research. Orders enter only through `CommandIssuer.Issue`. Finding the HQ is a linear scan of players; index it when player counts grow.
- 2026-10-16 — **The GDD `FleetUnit` class is split into five components** (`FleetUnit`, `FleetMotion`, `FleetReadiness`, `FleetCombatState`, `FleetSensors`), each with one owning system (rule 4); a fleet's cargo hold is its own `Stockpile`. `FleetPresence` is gone.
- 2026-10-16 — **Fleet movement**: a `Move` takes a lane or a destination site (routed once at the order, Sprint 4). Base speed 5 units/tick and 1 fuel per ship per 100 length units (× tier fuel) are PROVISIONAL, paid at departure, rounded up.
- 2026-10-16 — **Unpaid upkeep grounds the fleet** (`IsUnsupplied`: can't move or fire) instead of hull decay; upkeep is all-or-nothing per hour. PROVISIONAL.
- 2026-10-16 — **Salvo combat numbers are PROVISIONAL** (`CreateCombatBalance`): Alpha 10, Beta 20, HP 100/60/80/50 (Line/EW/Supply/Cargo), 100 milli ammo/battery per ship per salvo, ambient 20 °C, +4 °C fire heat, −4 °C passive, −15 °C per vent (200 milli coolant), tender transfer 2 up to 10. Each player targets the lowest-id hostile player at the location. Combat burns 20 milli fuel per acting ship per salvo × the tab-03 fuel multiplier (Sprint 4).
- 2026-10-16 — **Drill retract applies at every depth** (GDD §2.1 B names it for core fracture); rigs are freed after 180 ticks.
- 2026-10-16 — **Capital relocation as built** (`CapitalRelocationSystem`): both phase costs are paid upfront from the old core base (PROVISIONAL: 20 alloy + 50 fuel + 20 battery; 20 coolant + 20 battery); durations are rolled uniformly within the sheet ranges with a stateless `SplitMix64`; the capital convoy is a 1-cargo-ship fleet that waits at the old base (it does not travel) and must survive the phase; a refused order costs nothing. "−50% SiteDefenseBonus" is read as keeping 50% of the +35% fortification.
- 2026-10-16 — **Focused radar placeholders** (`FocusedRadarSystem`): only outer-rim bypass lanes can be scanned, one scan per player per lane. Batteries (startup and ECM) come from the payer's core-base stockpile until fleets carry cargo. A reveal lasts 60 ticks (provisional). A fleet flagged `Reverse` escapes the reveal until Sprint 3 movement makes it actually leave the lane. ECM is only possible after the RWR alarm.
- 2026-10-16 — **Sprint 4 PROVISIONAL values** (all in `DefaultGameBalance`, none from the sheet): starting credits 10,000; refinery upkeep is paid from the wallet and, when it can't be, stays as debt in `AccruedUpkeep`; combat fuel 20 milli per ship per salvo; routes hold at most 32 lanes; STA toll 2 credits per ship per 100 length units; the wallet lives on the player HQ; before the first trade the VWAP is tab-01 `Base_WTO_Price`; WTO price band ±20% over a 100-tick window.
- 2026-10-16 — **WTO escrow contracts as built**: the seller's deposit is the escrow rate × the sell limit price; the convoy is a Tier-1 cargo fleet launched from the seller's site with route fuel and upkeep; the deadline is 200% of travel time + 600 ticks, after which the buyer is compensated pro rata and the convoy stays the seller's. Loot: a destroyed fleet's hold goes to the lowest-index surviving hostile player fleet at the same site or lane; contract and stolen cargo become `StolenGoods`, which the WTO refuses. `DelayedPlayerCommand` gained `ParamC` (price); nothing is serialized yet.
- 2026-10-16 — **Leaderboard audit as built**: daily (86,400 ticks), opt-in; net worth = credits + site and fleet stock at the WTO reference price; brackets by rank (tab 05). Grants are paid in credits because the pools hold only credits (the sheet names FUEL/COOLANT/STEEL/ALLOY). Players who leave the audit while in a bracket are "evading" and pay 40% escrow.
- 2026-10-16 — **Call-to-Arms reading** (`SystemAuthorityManager`): the GDD names two threshold layers but no numbers. Offences are WTO contract piracy, counted over a day. Layer 1 (1st offence): the WTO bars the offender's orders for 1 h. Layer 2 (3rd): a WTO defence fleet of 20 Tier-1 line ships appears at the offender's core base for 1 h, with a public bulletin. System fleets (negative owner ids) leave no loot. Toll evasion and nuclear strikes are not offences yet (tolls are refused, not evaded; strikes have no player cause until the nuke weapon exists).
- 2026-10-16 — **NOAA forecast is exact**: brackets see the very fronts the seeded weather will roll within their lead (tab 05), because rolls are stateless per (seed, tick, cluster). Unrated players get no forecast.
- 2026-10-16 — **Utility AI as built** (`UtilityAiEngine`): off the sim clock, so the host can run it on Server 2; orders go through `CommandIssuer` like a player's. Considerations read 500 at their threshold up to 1000 at the extreme; a can-do consideration (coolant, fuel) vetoes at 0. PROVISIONAL: power = line ships × Alpha + EW × Beta; 100% battery = 10 scan startups at the core base; resupply below 5 ammo per line ship means going home. Stealth_Raid and Siege_Conquest weights have no actions yet; orders still in flight can be issued again (handlers ignore duplicates).
- 2026-10-16 — **UI theme as built** (style pass S1): fonts are Chakra Petch (Google Fonts) and IBM Plex Sans/Mono, all SIL OFL 1.1, licences beside them; Plex Sans comes as static weights from IBM's repo because Google Fonts ships only a variable file. UI Toolkit has no `text-transform` and no dashed borders, so display text is written upper case in the data and `DashedFrame` draws the dashed "in flight" border. FontAssets are dynamic: if the editor saves glyph atlases into them, clear their dynamic data before committing.
- 2026-10-16 — **New game setup as built** (`NewGameSetup`, `CreateNewGameBalance`): every participant (player + 4 AI rivals, archetypes 1..4) gets a home system, cluster = participant index, seeded from the world seed; systems are not linked until jump gates exist. Deposits follow the tab-01 preferred ESI windows (2 per site, nearest window if none holds); homes hold no tungsten/uranium. The core base is the highest-ESI home site. PROVISIONAL: reserves 2,000/4,000/1,000, 2 rigs per core-base deposit, refineries O2/coolant/fuel/steel/battery, the core stock and the Tier-1 10/2/2 fleet.
- 2026-10-16 — **The game runs in-process for now**: `GameSession` (View) owns the `SimulationWorld`, advances one tick per real second and calls `Ai.Think` after each tick, until Server 2 hosts the simulation. A frame that falls more than 120 ticks behind drops the backlog.
- 2026-10-16 — **Research as built** (`ResearchSystem`, `TechProgress` on the HQ): the GDD names 4 branches × 5 tiers × 3 stages but never the branches, so research is one track per tier (tier 1 known, tiers 2..5 researched) until branches are designed. Telemetry: fleets with ≥5 microchips aboard (not consumed) in a storm add level × 1 milli per tick toward 1,000. Stress test: a `StressTest` command at the core base, cost = 10 of each tab-03 build item of the tier; a blast is a NOAA bulletin (global; the "3 hops" radius is for the views). Retooling 1/2/4/8 h. Retrofit moves to the shipyard step. All PROVISIONAL except P_base and the +18% pity.
